Detailed Description

template<typename I, typename C>
class orpp::fdistribution< I, C >

Finite discrete distribution.

Template Parameters
Itype of the values
Ctype of the condition
listdefvay of atoms definition:

listdef=true indicates that the atoms are primarily determined by an overloading of atoms_are while atom_is and natom_is need not be overoaded as they use atoms_are. If listdef=false then the atoms are determided by overloading of natom_is and atom_is while atoms_are needs not be overloaded.
