Detailed Description

template<typename E, typename D, typename Z>
class orpp::ivdistribution< E, D, Z >

Iteratively defined std::vector distribution.

Template Parameters
Dconditional distribution of the std::vector's component
Zmapping from a history of the distribution into the condition of D

The distribution is defned iteratively, the i-th component being conditioned by {Z}(s)$ where s is the scenario containing previous values of the std::vector. Template parameter Z has to be a descendant of zeta<X, C> where X is the type of D's values and C is the type of its condition.
